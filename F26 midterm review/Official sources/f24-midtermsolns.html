lm(y ~ x, data = dat)
  1. \(y = \beta_0 + \beta_1q + \beta_2z + \beta_3(q\times z) + \epsilon\)
lm(y ~ q*z, data = dat)

Using poly without raw = TRUE is not correct as it will carry out the orthogonalization that is not represented in that regression equation.

For each of the following models, write out the linear regression equation they represent. Assume z has three unique values, ({1, 2, 3}), and is stored as a numeric in dat. Do not forget the intercept if needed.

  1.  

    lm(y ~ x + as.factor(z), data = dat)

    \(y = \beta_0 + \beta_1x + \beta_2z_2 + \beta_3z_3 + \epsilon\)

  2.  

    lm(y ~ I(x + 2) + I(z^2), data = dat)

    \(y = \beta_0 + \beta_1(x + 2) + \beta_2(z^2) + \epsilon\)

  3.  

    lm(y ~ x:z - x, data = dat)

    This one is kind of a trick question - x*z includes both main effects x and z (and thus -x removes it), whereas x:z doesn’t include main effects, so -x does nothing as no main effects are included.

Problem 6

Roulette is a betting game in which a ball is placed on a spinning disk (the roulette wheel) with 38 slots. As the wheel stops spinning, the ball ends up in one of these slots. Players can bet on the numeric value of the slot (1 through 36, as well as 0 and 00), or the color (18 red, 18 black, and 2 green).

  1. Write an R function, spin, that spins the roulette wheel. It takes in two arguments:

    • n: The number of spins
    • color: Whether color or value should be returned: TRUE returns the color, FALSE the value.

    The output should be a vector of length n containing either the colors (as character) or the values (as numeric). (Return -1 for value “00”.)

    You may use the sample function if desired; it takes in three required arguments and one optional argument:

    • x: A vector to sample from
    • size: The number of samples to draw
    • replace: Logical, sampling with (TRUE) or without (FALSE) replacement
    • prob: Optionally, a vector of the same length as x defining the probability of each value. It need not sum to 1; it will be scaled automatically.

    sample returns a vector of the same length as x.

    In number ranges from 1 to 10 and 19 to 28, odd numbers are red and even are black. In ranges from 11 to 18 and 29 to 36, odd numbers are black and even are red. Numbers 0 and 00 are green. (Hint: Does this matter?)

    Notes:

    • You do not need to sanitize the input - you may assume that n is an integer above 0, and that color is either TRUE or FALSE.
    • You do not need to document your function.
spin <- function(n, color = FALSE) {
    if (color) {
        results <- sample(c("red", "black", "green"), n, TRUE,
                          prob = c(18, 18, 2))
    } else {
        results <- sample(-1:36, n, TRUE)
    }
    return(results)
}

I used a simplification here - you could sample for color directly, rather than transforming the value into a color. If you went that route, your solution may look like this:

spin2 <- function(n, color = FALSE) {
  values <- sample(-1:36, n, TRUE)
  if (!color) {
    return(values)
  }
  colors <- character(length = n)
  colors[values <= 0] <- "green"
  colors[(values >= 1 & values <= 10) & values %% 2 == 0] <- "black"
  colors[(values >= 1 & values <= 10) & values %% 2 != 0] <- "red"
  colors[(values >= 11 & values <= 18) & values %% 2 != 0] <- "black"
  colors[(values >= 11 & values <= 18) & values %% 2 == 0] <- "red"
  colors[(values >= 19 & values <= 28) & values %% 2 == 0] <- "black"
  colors[(values >= 19 & values <= 28) & values %% 2 != 0] <- "red"
  colors[(values >= 29 & values <= 36) & values %% 2 != 0] <- "black"
  colors[(values >= 29 & values <= 36) & values %% 2 == 0] <- "red"
  return(colors)
}

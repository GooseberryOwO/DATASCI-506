For each of the following data cleaning steps, write R code to carry out the operation. You may use any R code (base R or tidyverse or other). New variables should be created inside mydata. Be sure to properly account for the possibility of missing values. (Hint: Most of these can be completed with 1 line of base R code. Some may need an additional line or two.)

Solutions note: There are of course many solutions to these problems.

  1. None of the numeric values should have negative values. Make any values less than 0 missing.
mydata[mydata < 0] <- NA

Alternately, you could it do a loop:

for (vars in c("patient_id", "age", "years_smoking", "systolic_bp",
    "diastolic_bp", "cholesterol", "outcome_score")) {
    mydata[[vars]][mydata[[vars]] < 0] <- NA
}

You could also do this manually:

mydata$patient_id[mydata$patient_id < 0] <- NA
mydata$age[mydata$age < 0] <- NA
etc...
  1. Generate a new variable representing the mean arterial pressure.
mydata$mean_arterial_pressure <- (2*mydata$diastolic_bp + mydata$systolic_bp)/3

Missing values will propogate fine.

  1. Generate a new variable called smoking indicating whether a patient smokes (non-zero years smoking).
mydata$smoking <- mydata$years_smoking > 0

Missing values will again propogate.

  1. Convert sex to a binary variable called female.
mydata$female <- mydata$sex == "Female"
mydata$female[mydata$sex == ""] <- NA

Failing to account for the potential missing values will result in missing genders being classified as female!

  1. Restrict the analysis to female patients.
mydata <- mydata[mydata$female, ]
  1. Remove any patient who is outside the age range of 18-65.
mydata <- mydata[mydata$age >= 18 & mydata$age <= 65, ]
  1. Scale the outcome to be between 0 and 1.
mydata$outcome_score <- (mydata$outcome_score - min(mydata$outcome_score))/
                        (max(mydata$outcome_score) - min(mydata$outcome_score))

Note that just dividing by the max, or 100, or some large value, would work here, because I didn’t specify that the outcome had to have values across the entire range from 0 to 1. This wouldn’t work if you had negative values, but part a. took care of that. Technically I don’t like dividing by 100, because you don’t know (with the information you have) what the max is, but I see how you got there and accepted it.

  1. Fit a linear regression model predicting the outcome score based upon
  • Treatment (categorical)
  • Age/Mean arterial pressure interaction (with main effects)
  • Cholesterol (cubic relationship)
mod <- lm(outcome_score ~ as.factor(treatment) + age*mean_arterial_pressure + poly(cholesterol, 3),
    data = mydata)

Since treatment is a character, you didn’t have to explicitly convert it to a factor. Also, cholesterol + I(cholesterol^2) + I(cholesterol^3) is fine as well.

  1. Calculate the average predicted value from your model.
mean(predict(mod))

fitted(mod) and mod$fitted.values works as well. Additionally, you could have created a single mean observation and passed that to predict, but note that only works on linear models - it would not be the same on non-linear models such as logistic regression.

Problem 6

Sticker Collecting. There are mystery stickers packs you can buy from the store. Each pack contains 1 sticker; There are five possible stickers (“A” through “E”). There are two different packs you can buy:

  • Pack 1: $5 - Equal 20% chance for each of the five stickers.
  • Pack 2: $2 - 30% chance for stickers “A”, “B” and “C”; and only 5% for “D” and “E”.

You do not need to sanitize any input. You do not need to document any functions. Functions do not need to be efficient, but you will get minor extra credit for making them so.

For any part of this problem, you may use the sample function if desired; it takes in three required arguments and one optional argument:

  • x: A vector to sample from
  • size: The number of samples to draw
  • replace: Logical, sampling with (TRUE) or without (FALSE) replacement
  • prob: Optionally, a vector of the same length as x defining the probability of each value. It need not sum to 1; it will be scaled automatically.

sample returns a vector of the length size.

  1. Write an R function, open_pack, that returns a sticker according to these probabilities. Input:
  • pack_type: Values 1 or 2

The output should be a character of length one, indicating the sticker

open_pack <- function(pack_type) {
  if (pack_type == 1) {
probs <- rep(.2, 5)
  } else if (pack_type == 2) {
probs <- c(.3, .3, .3, .05, .05)
  }
  return(sample(LETTERS[1:5], 1, replace = TRUE,
            prob = probs))
}
open_pack(1)

open_pack(2)
[1] "B"
  1. Write an R function, open_packs, that opens multiple packs at once. Inputs:
  • pack_type: Values 1 or 2
  • n: The number of packs to open.

The output should be a vector of length n containing the stickers received.

Notes: - You do not need to use open_pack inside open_packs, but you may.

open_packs <- function(pack_type, n) {
  if (pack_type == 1) {
probs <- rep(.2, 5)
  } else if (pack_type == 2) {
probs <- c(.3, .3, .3, .05, .05)
  }
  return(sample(LETTERS[1:5], n, replace = TRUE,
            prob = probs))
}

  1. You have $40. You can only buy one type of packs (i.e. either 8 of pack 1, or 20 of pack 2). Which set of packs gives you a higher probability of getting a complete set of all five stickers? Write a Monte Carlo simulation to estimate the percent of time that $40 yields getting a complete set to help you answer the question. Write an R function, spend40, that carries out the simulation for a single type of pack. Use either open_pack or open_packs. Inputs:
  • pack type: Values 1 or 2
  • reps: How many replications should the simulation perform

The output should be a single percentage indicating the percent of the runs which yielded a complete set.

Hint: The unique function may be useful.

spend40 <- function(pack_type, reps = 1000) {
  if (pack_type == 1) {
stickers <- open_packs(1, 8*reps)
dim(stickers) <- c(8, reps)
  } else if (pack_type == 2) {
stickers <- open_packs(2, 20*reps)
dim(stickers) <- c(20, reps)
  }

  completesets <- apply(stickers, 2, function(x) {
length(unique(x)) == 5
  })

  return(mean(completesets))
}
spend40(1, 10000)
[1] 0.3141
spend40(2, 10000)
[1] 0.4042

So the second packs are a better investment to complete the whole set.

Note: In the exam, I mistakenly gave only $20. In that case, obviously you cannot get the complete set of 5 stickers with only 4 of pack 1. However, even though you knew the answer, you still could carry out the simulation.
